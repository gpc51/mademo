# BHP Deck v1

Presentación ejecutiva en HTML, CSS y JavaScript puro.

## Uso

- Flechas, espacio o Page Up/Page Down para navegar.
- `F` para entrar en pantalla completa.
- Puede imprimirse como PDF desde el navegador.

## Modelo de ROI

Abrir `roi-model.html` para calcular el retorno por unidad con las variables BHP validadas: horas de detención, costo por hora, reducción observada y costos completos del programa.
